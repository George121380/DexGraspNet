### 仅正样本、灵巧手多接触点情况下的 Critic 训练方案（draft）

目标：在只有成功抓取数据（正样本）且接触点为若干（多指/多接触）条件下，训练一个 Critic 模型，输入为对象几何与候选抓取（接触集合 + 手/腕姿/方向等），输出为可行性分数 s ∈ [0,1]。

### 一、输入与表示
- 对象输入：点云 P_obj（FPS到固定点数）；可选法线/曲率（若可计算）。
- 抓取输入：
  - 接触集合 C = {c_i ∈ R^3 | i=1..K}，可选接触法线 n_i、接触面切向基（若可得）。
  - 手部全局信息：腕位姿 T_wrist（平移+旋转6D）、指关节角 q（若可得）。
  - 任务/动作参数：如上抬/推/旋转等（与 DualAfford 一致，编码为低维 task 向量）。
- 模型结构建议：
  - 对象分支：PointNet++/Point-BERT 等提取全局特征 f_obj。
  - 接触集合分支：PointNet式 per-contact MLP（共享权重）→ 对 K 个接触做对称聚合（max/mean/attention）→ f_ctpt。
  - 姿态/任务分支：MLP(task)、MLP(6D姿态)、MLP(q) → f_task, f_pose, f_joint。
  - 融合：concat(f_obj, f_ctpt, f_task, f_pose, f_joint) → MLP → 标量分数。

### 二、监督信号设计（无真实负样本）
采用“几何代理 + 排序/一类学习 + 伪负样本”组合，解决无负样本监督问题。

1) 几何代理分数（proxy quality，回归损失）
- 为每条成功演示（P_obj, C, T_wrist, q, task）构造一个几何质量分数 Q ∈ [0,1]，作为软标签：
  - 法线对齐：cos(接触法线, 手/指接触方向) 的均值/最小值。
  - 接触覆盖：接触点在物体表面的分散度/覆盖率（例如最小生成树边长和、pairwise距离分位数）。
  - 渗透/穿透惩罚：手-物体距离 < 0 的比例或幅度（若可估或已有 SDF/碰撞近似）。
  - 抓取姿态稳定性先验：接触点相对于重力/质心分布是否利于稳定（启发式）。
- 将 Q 归一化到 [0,1]，对正样本做回归：L_reg = |s_pred − Q|。

2) 基于距离的相对排序（Ranking，无需真负样本）
- 对每个正样本，生成若干“退化变体”（视作弱样本）：
  - 接触点扰动：对每个 c_i 添加高斯噪声/向物体边界偏移；
  - 接触子集/遮挡：随机删除部分接触点（降低覆盖率）；
  - 姿态扰动：旋转偏离法线、改变腕位移、注入少量关节噪声；
  - 方向违背：将作用方向与表面法线相反或偏离过阈值；
- 定义 margin 排序损失：L_rank = max(0, m − s_pos + s_var)，m 为间隔（如 0.2）。
  - 只需要“正样本 vs 退化样本”的相对关系，不依赖真负标签。

3) 一类学习（One-Class，自监督）
- 让正样本特征分布紧致：
  - Deep SVDD/Center Loss：特征嵌入 z 逼近全局中心 c，L_oc = ||z − c||^2；
  - 或能量最小化：正样本能量 E(x) 较低，退化样本能量较高；可与 L_rank 结合。

4) 伪负样本（Unlabeled Negatives，弱监督）
- 通过规则生成“显然不可行”的抓取：
  - 手部整体远离物体（> d_max），无接触或接触点不在表面；
  - 接触点高度集中/共线/同侧，明显不稳定；
  - 作用方向与表面法线夹角接近 180° 且超过阈值；
- 将这些样本标为 0 分或低分（如 0~0.2），与正样本形成弱监督的 BCE/L1。

综合损失：
L = λ1·L_reg + λ2·L_rank + λ3·L_oc + λ4·L_weakBCE
（建议起始 λ1=1, λ2=1, λ3=0.1, λ4=0.5，后续可调）

### 三、训练策略
- 批构造：每个正样本配 M 个退化变体 + U 个伪负；pos:neg ≈ 1:(M+U)。
- Curriculum：
  - 前期以退化/伪负的“易”样本为主（大扰动/明显不合理）；
  - 中后期增加“难”变体（小扰动/局部合理），逐步提高判别精度。
- Hard Mining：使用当前 critic 对大量未标注候选（由接触点/动作采样器生成）打分，选出高分却几何代理差的案例作为难负样，进一步训练（自举）。

### 四、采样与增强（适配多接触）
- 退化样本生成：
  - 点级扰动：对每个 c_i：法线方向 ±ε_n、切向 ±ε_t，截断到表面附近；
  - 组级扰动：随机丢弃 r 个接触（r∈[1,⌊K/2⌋]），或将子集向同一侧集中；
  - 姿态/关节扰动：T_wrist 小角度旋转、q 添加小噪声；
- 保证约束：对扰动后样本做几何检查（距离到表面、穿透近似），过滤掉过于异常、不可计算的样本。

### 五、实现与验收
- 模型改造：
  - 将单接触 `mlp_cp(3→d)` 扩展为“多接触共享 MLP + 对称聚合”获得 f_ctpt；
  - 其余分支（task/pose/joint）与 DualAfford 类似；
- 训练流程：
  - 仅需成功演示数据（positives）与物体 mesh/点云；
  - 在线生成退化/伪负；
  - 组合损失训练 critic；
- 验收指标：
  - 正样本召回率（s>τ）
  - 自生成负样本的拒识率
  - 真实部署/仿真的 A/B 测试成功率（若可）

### 六、可选增强
- 几何代理蒸馏：若有轻量启发式打分器（覆盖/法线对齐/GWS近似），可作为 teacher 生成更平滑的 Q。
- 多视角一致性：同一对象多视角点云经过 critic 输出应一致（视角不变性约束）。
- 对比学习：把（同一正样本的增强）拉近表示，把退化/伪负推远，提高判别边界鲁棒性。

### 七、超参建议（初始）
- 点数：对象点云 8k；接触数 K 原始；若 K 很大可随机子采样到 16~32。
- 退化变体数 M=8，伪负 U=8；margin m=0.2。
- 学习率 1e-3，batch size 16~32，训练 50k~100k steps。
